راهنمای قدم‌به‌قدم

این راهنما اسکلت کار است، نه نسخهٔ پیچیده‌شده: گام‌ها از مرحلهٔ همین پروژه و دیتاست و مهارت‌های خودش ساخته شده‌اند. تصمیم‌های ریز را خودت می‌گیری — که اصلاً نکتهٔ پروژه همین است.

گام ۱
دادهٔ «CORD» را بردار و اول فقط نگاهش کن. صد ردیف اولش را باز کن و سه چیز بنویس: چه ستون‌هایی دارد، کجایش خالی یا خراب است، و یک سؤال مشخص که با همین داده جواب دارد.
گام ۲
اول بدون fine-tune جلو برو: فقط با prompt خوب و خروجی ساختاریافته. در بیشتر پروژه‌ها همین کافی است و وقتت را نگه می‌دارد.
گام ۳
حالا سراغ مهارت اصلی این پروژه برو: Transformerها، Embedding، Token و Context Window، Prompting و Structured Output، Function Calling. این همان چیزی است که قرار است از این پروژه یاد بگیری؛ بقیه‌اش بستربندی است.
گام ۴
خروجی را با یک مجموعهٔ کوچک آزمون بسنج — بیست تا سی نمونه با جواب درستِ دستی. بدون این، نمی‌فهمی تغییر prompt بهتر کرده یا بدتر.
گام ۵
مخزن را مرتب کن و README را با همان پنج تیتر بنویس: مسئله ← داده ← روش ← نتیجه ← دمو. یک تصویر یا گیف از خروجی بگذار؛ کسی که رزومه‌ات را می‌خواند، کد را باز نمی‌کند.
تمام‌شده یعنی چه

یک مجموعهٔ آزمون کوچک داری و می‌توانی بگویی نسخهٔ امروز از نسخهٔ دیروز بهتر است یا نه، با عدد.
