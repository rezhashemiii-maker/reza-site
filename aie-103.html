راهنمای قدم‌به‌قدم

این راهنما اسکلت کار است، نه نسخهٔ پیچیده‌شده: گام‌ها از مرحلهٔ همین پروژه و دیتاست و مهارت‌های خودش ساخته شده‌اند. تصمیم‌های ریز را خودت می‌گیری — که اصلاً نکتهٔ پروژه همین است.

گام ۱
دادهٔ «US DOT Flight Delays (Kaggle)» را بردار و اول فقط نگاهش کن. صد ردیف اولش را باز کن و سه چیز بنویس: چه ستون‌هایی دارد، کجایش خالی یا خراب است، و یک سؤال مشخص که با همین داده جواب دارد.
گام ۲
کوچک‌ترین نسخهٔ کارکننده را بساز: یک اسکریپت که داده را می‌خواند، تمیز می‌کند و یک جدول خروجی می‌دهد. هنوز خبری از رابط کاربری نیست.
گام ۳
حالا سراغ مهارت اصلی این پروژه برو: Functions، Classes و Data Structures، Git و APIها، NumPy، Pandas و SQL. این همان چیزی است که قرار است از این پروژه یاد بگیری؛ بقیه‌اش بستربندی است.
گام ۴
خروجی را به چیزی تبدیل کن که بشود نشانش داد: یک داشبورد ساده یا چند نمودار که بدون توضیح تو هم فهمیده شود.
گام ۵
مخزن را مرتب کن و README را با همان پنج تیتر بنویس: مسئله ← داده ← روش ← نتیجه ← دمو. یک تصویر یا گیف از خروجی بگذار؛ کسی که رزومه‌ات را می‌خواند، کد را باز نمی‌کند.
