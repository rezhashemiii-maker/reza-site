# صادرات خام آرتبوردهای آرتیفکت

این‌ها نسخهٔ **دست‌نخوردهٔ** آرتبوردهایی‌اند که روی آرتیفکت طراحی
(claude.ai) ساخته شده‌اند و `tools/gen/port.py` آن‌ها را به `src/`
منتقل می‌کند.

چرا این‌جا نگه داشته می‌شوند:

- بدون آن‌ها، `src/Writing.dc.html` و شصت‌ویک فایل دیگر خروجیِ بدون
  منبع بودند و `tools/gen/run.py` روی هیچ ماشین دیگری اجرا نمی‌شد.
- `git diff tools/gen/artifact/X.dc.html src/X.dc.html` دقیقاً نشان
  می‌دهد انتقال چه چیزی را عوض کرده است.

**این فایل‌ها را دستی ویرایش نکنید.** مبدأشان آرتیفکت است؛ تغییر را
آن‌جا بدهید و دوباره صادر کنید. تغییرهایی که مخصوص مخزن‌اند (برداشتن
جانگهدارها، h2→h1، پیوند کمپین) در `port.py` نوشته می‌شوند تا هر بار
صادرات تازه هم همان‌ها را بگیرد.

## out/ — جهتِ مخالف

فایل‌های `out/` برعکسِ بالایی‌هایند: از `src/` ساخته می‌شوند تا روی
آرتیفکت منتشر شوند، با `tools/gen/artifact_export.py`. در مخزن نگه
داشته نمی‌شوند، چون هر وقت لازم شد از `src/` دوباره ساخته می‌شوند.
